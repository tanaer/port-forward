## 📊 主要功能说明

### 1. 节点管理
- **注册节点**: 通过gRPC注册代理端
- **健康检查**: 自动检测节点状态
- **节点隔离**: 故障节点自动隔离
- **批量操作**: 支持批量重启、状态更新

### 2. 配置管理
- **配置下发**: 实时推送给代理端
- **版本管理**: 每次配置变更自动创建版本
- **配置回滚**: 一键回滚到任意历史版本
- **批量配置**: 支持批量创建和更新

### 3. 回滚系统
- **任务跟踪**: 完整的回滚任务状态管理
- **自动重试**: 失败任务自动重试（最多5次）
- **超时检测**: 10分钟无响应的任务自动重置
- **死信队列**: 超过重试次数的任务移入DLQ

### 4. 可观测性
- **Prometheus指标**: 实时指标导出
- **Grafana仪表板**: 预配置的11个监控面板
- **实时监控**: WebSocket推送节点状态变更
- **任务统计**: 成功率、失败率、执行时间等

### 5. 配置系统
- **多层级配置**: CLI参数 > 环境变量 > YAML文件 > 默认值
- **环境变量**: `GOFORWARD_*` 系列环境变量
- **YAML文件**: `goforward.yaml` 配置文件模板
- **动态重载**: 支持配置热更新

## ⚙️ 配置文件 (goforward.yaml)

v2.0.0 使用 `goforward.yaml` YAML 配置文件来控制启动参数。

### 配置优先级 (从高到低)
1. **环境变量**: `GOFORWARD_*` 系列环境变量（最高优先级）
2. **YAML 文件**: `goforward.yaml` 配置文件
3. **默认值**: 内置默认配置（最低优先级）

### 常用配置项

```yaml
# 服务器配置
server:
  port: "8890"           # Web 管理界面监听端口 (默认: 8889)
  password: ""           # Web 管理界面密码 (可选)

# 回滚系统配置
rollback:
  enabled: true                          # 是否启用回滚系统 (默认: true)
  max_retries: 5                        # 最大重试次数 (默认: 5)
  processing_timeout: 600s              # 处理超时时间 (默认: 600s)
  stalled_scan_interval: 60s            # 超时任务扫描间隔 (默认: 60s)

# Prometheus 指标配置
metrics:
  enabled: true                         # 是否启用 Prometheus (默认: true)
  port: "9090"                          # Prometheus 监听端口 (默认: 9090)
  scrape_interval: 15s                  # 采集间隔 (默认: 15s)

# 日志配置
logging:
  level: "info"                         # 日志级别: debug, info, warn, error
  format: "text"                        # 日志格式: json, text
  output: "stdout"                      # 日志输出: stdout, file
```

### 使用示例

**修改 Web 监听端口到 9999:**
```yaml
server:
  port: "9999"
```

**禁用 Prometheus 指标:**
```yaml
metrics:
  enabled: false
```

**设置 Web 密码:**
```yaml
server:
  password: "your-secure-password"
```

### 环境变量覆盖

YAML 配置可以被环境变量覆盖，例如：

```bash
# 这会覆盖 YAML 中的 server.port 设置
export GOFORWARD_PORT=9999
./goForward_v2

# 其他常用环境变量:
export GOFORWARD_PASSWORD=mypassword
export GOFORWARD_METRICS_ENABLED=false
export GOFORWARD_LOG_LEVEL=debug
```

## 🌐 Web界面功能

访问 `http://localhost:8890` 可以看到v2.0.0的Web界面（或者您在 goforward.yaml 中配置的端口）：

### 页面功能
- **节点列表** (`/nodes`): 显示所有代理节点
- **节点详情** (`/nodes/:id`): 节点详细信息
- **配置列表** (`/configs`): 显示所有配置
- **配置详情** (`/configs/:id`): 配置版本历史

### API接口
- **节点API** (`/api/nodes`): 节点CRUD操作
- **配置API** (`/api/configs`): 配置CRUD操作
- **DLQ API** (`/api/dlq/tasks`): 死信队列管理
- **WebSocket** (`/ws`): 实时事件推送

## 📊 Prometheus监控

访问 `http://localhost:9090/metrics` 查看Prometheus指标：

### 核心指标
- `rollback_tasks_total`: 回滚任务总数
- `rollback_tasks_success_total`: 成功任务数
- `rollback_tasks_failed_total`: 失败任务数
- `rollback_tasks_processing`: 处理中任务数
- `grpc_requests_total`: gRPC请求数
- `grpc_request_duration_seconds`: gRPC响应时间

### Grafana仪表板
1. 添加Prometheus数据源: `http://localhost:9090`
2. 导入模板: `grafana/rollback-system-dashboard.json`
3. 查看11个监控面板

## 🗄️ 数据库结构

v2.0.0使用SQLite数据库，自动迁移到v8版本：

### 核心表
- `nodes`: 节点信息
- `proxy_configs`: 代理配置
- `node_logs`: 节点日志
- `config_versions`: 配置版本
- `rollback_tasks`: 回滚任务
- `rollback_tasks_dlq`: 死信队列

### 数据库文件
- 默认路径: `/tmp/goForward_control.db`
- 可通过环境变量设置: `GOFORWARD_DB_DIR`

## ⚠️ 注意事项

### 端口占用
如果启动时提示端口被占用：
```bash
# 检查端口占用
netstat -tuln | grep 8889

# 修改配置文件使用其他端口
echo "server:
  port: \"9999\"" > goforward.yaml
```

### Prometheus重复注册
如果有重复注册警告，这是启动顺序问题，不影响功能。

## 💡 常见问题

### Q: Web界面无法访问？
A: 检查端口是否被占用，尝试使用不同端口。

### Q: gRPC端口占用？
A: 修改grpcAddr变量，使用其他端口如`:50052`。

### Q: 数据库文件位置？
A: 默认在/tmp目录，可通过环境变量配置。

### Q: 如何备份数据？
A: 复制SQLite数据库文件即可。
